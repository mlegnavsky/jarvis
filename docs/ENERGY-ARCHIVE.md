# Private energy archive

Native domain jarvis_energy_archive captures graph power/SOC/spot plus battery charge/discharge, losses and daily/lifetime energy counters every10 seconds. It preserves source last_updated; repeated samples do not imply a new physical measurement. Unavailable values stay null. Weather and spot publications retain original fetched_at and complete attributes (including future delivery times); weather remains forecast, not measured conditions.

The durable SQLite outbox lives under HA .storage, max64MiB of queued JSON. A full queue pauses capture and reports error; it never deletes unacknowledged data. Retry batches have stable SHA256 IDs; remote acknowledgement must match before removal. No credentials in states/browser/Git. URL and host are fixed, TLS verified, redirects denied. Credentials are reused internally from the single existing jarvis-backup WebDAV config entry at laborator.odladeni.cz.

Server PHP endpoint /energy-archive/index.php stores SQLite outside webroot in sibling jarvis-energy-archive/. Existing private ha-backups/access.json authenticates access. Unauthenticated requests fail before storage creation. POST is immutable/idempotent, GET supports status/day, DELETE unsupported. All original batches retained compressed alongside indexed sample/publication rows. This duplicates content for audit/recovery but is not a backup against loss of the server. Server-level independent backup remains necessary; this code does not prove Plesk backup configuration.

GET status reports actual database/compressed bytes and free disk space. The HA sensor estimates annual database size only after one hour of samples; initial estimate is not a measured full-year footprint. SQLite index/growth means extrapolation is approximate. No automatic server deletion/retention; monitor space.

Authenticated HA GET /api/jarvis_energy_archive/day?date=YYYY-MM-DD proxies day data without giving browser server credentials. Prague day boundaries handle23/25hour DST. Existing graph uses archived samples if available, preserves fallback when absent, and can display archived forecast/spot rows. Old deleted raw measurements cannot be reconstructed. Historical backfill from current recorder and cloud/inverter export is not implemented in this version; collection begins only after verified activation.
