# Owner-started voice calibration

Owner approved implementation after the existing voice-only calibration deadlock was explained. Use the established authenticated revision-bound jarvis.admin file_write channel, not a new network service or a voice command. A fresh, single-use control request starts a ten-minute session for an existing authorized stable profile and the configured physical satellite. Collect five clean active-turn embeddings into a separate bounded private store even if the current matcher rejects them. During collection return progress only: no identity assertion, memory access or device-control grant. Keep anchors, live templates, matching thresholds and authorizations unchanged. Samples are owner-labelled but unreviewed, never automatically genuine holdouts or live/replay evidence. No raw audio. Restart must not replay requests or reset progress; stale/duplicate/wrong-device/bad-quality/playback samples must not grant authority. Completion means collection ready for review, not recognition repaired. Alternatives rejected: lowering match threshold without negative validation; requiring already-recognized voice (the deadlock).
