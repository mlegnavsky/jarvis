# Jarvis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Build an installable Home Assistant OS app for inventory, controlled actions, and versioned maintenance.
**Architecture:** Python service on Green uses Supervisor Core REST/WebSocket proxy. External authenticated API is separately routed through Cloudflare; existing hostname currently routes to Core, not this app. Supervisor manages app installations and updates.
**Tech Stack:** Python, aiohttp, Home Assistant OS app manifest, Docker, GitHub Actions.
**Spec:** Approved design in conversation on 2026-10-26, captured below.

## Approved scope
Read current states, device/entity/area registries, services, automation states and system versions. Mark freshness and connection loss. Authenticate remote access, allowlist actions, audit mutations. Version releases, back up before updates, verify recovery. Never commit credentials or household inventories. Green is aarch64; installed Core was reported as 2026.6.4. Real-device tests remain required.

## Global Constraints
- Credentials only in app options/environment; no credentials or real inventory in repository/logs.
- Existing HA automations must keep operating independently of Jarvis.
- No arbitrary shell, arbitrary URL proxy, or unrestricted filesystem writes.
- Initial deployment and remote ChatGPT authorization require explicit setup on real installation.
- Public source repository does not expose the house.
- Do not claim automatic rollback until tested on Supervisor.

## Review Focus
- Disconnected HA: report unavailable; never present cached values as current.
- Registry command unsupported by installed Core: partial inventory with explicit errors.
- Unauthorized caller: no inventory or action data disclosed.
- Retried action: idempotency key prevents duplicate execution.
- Self update interruption: persistent job state; no claim of success before post-restart verification.
